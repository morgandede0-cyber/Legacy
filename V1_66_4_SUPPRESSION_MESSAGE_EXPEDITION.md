# Altherya V1.66.4 — Nettoyage automatique des expéditions

- Le message public de suivi d'une expédition est désormais supprimé automatiquement dès la fin de l'expédition.
- Le transfert du butin vers l'inventaire reste effectué avant la suppression du message.
- Si Discord refuse exceptionnellement la suppression, le message est neutralisé et les boutons sont retirés.
- Aucun changement sur les loots, outils, sacoches, durées ou progression.
