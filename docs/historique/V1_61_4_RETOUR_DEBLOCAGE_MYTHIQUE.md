# V1.61.4 — Retour Thorgar + verrou Mythique

- Ajout d'un bouton **Retour** sur les deux carrousels de sélection de set (Achat et Amélioration), qui ramène directement au menu principal de Thorgar.
- **Casque, Gantelets et Bottes Mythiques** sont désormais verrouillés tant que le joueur n'a pas obtenu au moins une pièce Mythique.
- Une pièce Légendaire conserve le déblocage, puisqu'elle implique que le palier Mythique a déjà été atteint.
- Le verrou est appliqué à la fois dans l'interface et côté base de données pour empêcher tout contournement.
