# V2.44 — Panel Admin complet

- Panel Admin installable/fixable dans un salon via `/admin_setup`.
- Déplacement via `/admin_move`, actualisation via `/admin_refresh`, ouverture privée via `/admin`.
- 4 catégories : Joueurs, Althérya, Admin, Discord.
- Joueurs : Gold, XP, niveau exact, inventaire/équipement, réputations par palier, cooldowns, resets ciblés.
- Althérya : étage Ashkar, régénération petites annonces, récompense globale, zones, événements, Gazette/annonce, déblocage activité.
- Admin : rôles Discord autorisés, logs, actualisation panel.
- Discord : avertissement, mute/unmute, kick, ban/unban, clear, lock/unlock, ajout/retrait rôle.
- Toutes les actions métier sensibles sont journalisées dans admin_audit.
- Sentinelle absente du panel Admin.
