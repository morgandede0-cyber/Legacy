# Altherya V2.42 — Mobile UX Polish

Passe d'ergonomie mobile sans changement des mécaniques de jeu.

- Hub Monde mobile compact : niveau + Gold visibles immédiatement.
- Hub Ville mobile compact : niveau + Gold visibles immédiatement.
- Navigation Monde/Ville conserve l'identité mobile du joueur lors des retours.
- Les HUD de mini-jeux affichent désormais `Gold` au lieu de l'abréviation `G`.
- Descriptions Components V2 enrichies pour Actualiser, Lancer, Monde, Classe et Entrer dans l'étage.
- Texte générique d'action remplacé par une formulation plus claire lorsqu'aucune description spécialisée n'existe.
- Affichage compact des fortunes : `Gold` remplace `G`.
- Aucun média supplémentaire : la version mobile reste légère.
- Économie, probabilités, progression, inventaires et base PostgreSQL inchangés.
