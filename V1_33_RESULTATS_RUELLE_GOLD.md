# V1.33 — Résultats publics de la Ruelle avec Gold

Le salon configuré via `/succes` publie désormais, comme pour les jeux :
- les gains/pertes de Gold lors des vols entre joueurs ;
- les gains du braquage réussi ;
- les pertes/amendes du braquage raté ;
- les échecs sans Gold restent annoncés de façon compacte.

Les achats, ventes, banque, forge, récompenses et autres actions économiques restent privés et visibles uniquement dans `/logs`.
