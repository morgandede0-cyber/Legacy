# V2.48.6 — Toggle FR / EN sur le vrai panneau public

- Le bouton 🇫🇷 FR / 🇬🇧 EN édite maintenant directement le message public d'accueil.
- Aucun message éphémère n'est créé lors du changement de langue.
- Le titre, les textes et le bouton COMMENCER / START sont actualisés sur le même message.
- Au clic sur COMMENCER / START, la langue actuellement affichée est enregistrée pour le joueur et utilisée pour tout son onboarding privé.
- Les variantes FR et EN du panneau sont enregistrées comme vues persistantes pour survivre aux redémarrages du bot.
