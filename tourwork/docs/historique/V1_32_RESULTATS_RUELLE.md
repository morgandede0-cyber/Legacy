# V1.32 — Résultats publics de la Ruelle sombre

Le salon configuré avec `/succes` publie désormais aussi des résultats publics compacts pour :
- vol réussi contre un autre joueur ;
- vol raté ;
- voleur pris sur le fait et tabassé ;
- braquage de banque réussi ;
- braquage de banque raté.

Ces annonces ne révèlent volontairement ni le montant volé, ni le butin, ni l'amende. Les détails économiques restent privés et sont uniquement disponibles dans le salon `/logs` réservé au staff.
