# V1.64.1 — Correctif Vigile / Salle clandestine

- Corrige le paiement de l'entrée auprès du Vigile.
- Après un paiement réussi, l'interaction Discord est maintenant acquittée immédiatement.
- L'écran bascule vers la salle clandestine avant l'envoi du journal économique.
- Le Gold ne peut donc plus être débité alors que l'interface reste bloquée devant le Vigile à cause d'une interaction expirée.
- Aucun changement aux règles d'accès : invitation, paiement Gold, VIP et pass journalier restent identiques.
