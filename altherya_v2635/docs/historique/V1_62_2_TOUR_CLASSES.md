# V1.62.2 — Tour d'Ashkar : classes & interface de combat

- L'adversaire est maintenant affiché dans une bulle circulaire en haut à droite, face à l'avatar Discord du joueur.
- Avant chaque étage, le joueur choisit une classe identique au système de l'Arène : Ravageur, Gardien ou Traqueur.
- La classe peut être changée librement entre deux étages et après une défaite.
- Les attaques et compétences reprennent les noms, emojis et mécaniques de l'Arène :
  - Ravageur : Griffes vives, Lacération, Fureur du Prédateur, Instinct sauvage.
  - Gardien : Patte du Colosse, Fracas terrestre, Courroux du Gardien, Forteresse.
  - Traqueur : Croc éclair, Assaut lunaire, Chasse Fantôme, Pas Fantôme.
- Les boutons Discord changent automatiquement selon la classe choisie.
- L'ultime possède le même principe de recharge sur 2 tours.
- Les bonus d'équipement de KHAZ'GORAM restent pris en compte.
